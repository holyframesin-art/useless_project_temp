# Malayalam Movie Roulette 🎯

### Team Name: SHAZIN


### Team Members

### Project Description
Malayalam Movie Roulette is a fun web application that recommends real Malayalam movies that are widely considered poor, disappointing, or low-rated.

Instead of helping users find the best movie to watch, the application does the exact opposite — it helps users discover movies that may make them question their life choices.

Each recommendation comes with a short description and a humorous Malayalam/Manglish-style roast explaining why watching the movie might be a terrible idea.

### The Problem (that doesn't exist)
Finding a good Malayalam movie is already easy.

But what if someone wants to watch something so questionable that they spend the next two hours asking:

**"Njan enthina ithu kandathu?"**

There is a serious shortage of technology dedicated to solving this completely unnecessary problem.

### The Solution (that nobody asked for)
Introducing **Malayalam Movie Roulette**.

The application randomly recommends a movie from a collection of real Malayalam movies known for poor reception, low ratings, or generally negative audience response.

Instead of saying:

**"You should watch this because it is amazing."**

our application says:

**"You wanted a bad movie. Congratulations. We found one."**

The user can repeatedly spin the roulette and discover another terrible movie recommendation — because apparently one bad decision is not enough.
